Kebijakan Privasi Kapsulmu

Terakhir diperbarui: 30 Agustus 2026

Kapsulmu ("kami", "aplikasi") dikembangkan sebagai aplikasi persiapan ujian kompetensi apoteker (UKAI). Halaman ini menjelaskan kebijakan kami terkait pengumpulan, penggunaan, dan pengungkapan informasi pribadi ketika Anda menggunakan aplikasi kami.

Dengan menggunakan Kapsulmu, Anda menyetujui pengumpulan dan penggunaan informasi sesuai kebijakan ini.

1. Informasi yang Kami Kumpulkan

1.1 Data yang Disimpan Secara Lokal

Kapsulmu tidak memerlukan pembuatan akun. Seluruh data berikut disimpan hanya di perangkat Anda menggunakan AsyncStorage (penyimpanan lokal), tanpa proses pendaftaran atau login:

  • Progress belajar per materi (persentase, status selesai)
  • Riwayat Try-Out (skor, waktu pengerjaan, jawaban yang dipilih)
  • Soal yang dibookmark
  • Preferensi tampilan (mode gelap/terang)
  • Pengaturan pengingat belajar (jam, status aktif/nonaktif)

Data ini tidak pernah dikirim ke server eksternal dan tidak dapat diakses oleh kami. Jika Anda menghapus aplikasi, seluruh data ini akan terhapus secara permanen dan tidak dapat dipulihkan.

1.2 Pembelian Kapsulmu Pro (RevenueCat)

Kapsulmu Pro adalah pembelian sekali bayar (lifetime, bukan langganan) yang diproses melalui App Store (Apple) atau Google Play, dan dikelola oleh RevenueCat sebagai penyedia layanan pihak ketiga kami untuk memverifikasi dan menyinkronkan status pembelian.

Saat Anda melakukan atau memulihkan (restore) pembelian, RevenueCat menerima:

  • Data transaksi dari App Store/Google Play (bukti pembelian, ID produk, tanggal)
  • ID anonim yang dibuat otomatis oleh RevenueCat untuk perangkat Anda (bukan nama, email, atau identitas pribadi — kami tidak memiliki sistem akun)

Data ini digunakan semata-mata untuk mengenali bahwa perangkat Anda memiliki akses Kapsulmu Pro yang sah, termasuk saat Anda memulihkan pembelian di perangkat baru. Lihat Kebijakan Privasi RevenueCat untuk detail lengkap. Kami tidak menerima atau menyimpan detail kartu pembayaran Anda — itu ditangani sepenuhnya oleh Apple/Google.

1.3 Notifikasi

Jika Anda mengizinkan notifikasi, kami menjadwalkan pengingat belajar harian secara lokal di perangkat Anda. Kami tidak menggunakan layanan push notifikasi pihak ketiga saat ini dan tidak mengirim data ke server untuk tujuan notifikasi.

1.4 Data yang Tidak Kami Kumpulkan

Kami tidak mengumpulkan:

  • Nama lengkap, email, atau nomor telepon (tidak ada pendaftaran akun)
  • Lokasi GPS
  • Data perangkat (IMEI, MAC address)
  • Detail kartu kredit/pembayaran (ditangani oleh Apple/Google, tidak melalui kami)
  • Data penggunaan atau analitik perilaku (tidak ada SDK analitik pihak ketiga selain yang disebut di §3)
  • Data dari kontak, kamera, atau mikrofon perangkat Anda

2. Cara Kami Menggunakan Informasi

Data yang dikumpulkan digunakan semata-mata untuk:

  • Menyimpan dan menampilkan progress belajar Anda di perangkat Anda sendiri
  • Mengirimkan pengingat belajar harian sesuai preferensi Anda

Kami tidak menggunakan data Anda untuk:

  • Iklan bertarget
  • Penjualan kepada pihak ketiga
  • Pembuatan profil perilaku

3. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, memperdagangkan, atau menyewakan data pribadi Anda kepada pihak ketiga.

Kami hanya berbagi data dengan penyedia layanan infrastruktur berikut, sebatas yang diperlukan untuk operasional aplikasi:

PenyediaTujuanData yang DibagikanKebijakan Privasi
RevenueCat Memverifikasi & menyinkronkan status pembelian Kapsulmu Pro Data transaksi App Store/Play Store, ID anonim perangkat revenuecat.com/privacy
Apple App Store / Google Play Memproses pembayaran Kapsulmu Pro Ditangani sepenuhnya oleh Apple/Google — kami tidak menerima detail kartu Anda apple.com/legal/privacy · policies.google.com/privacy

Selain pemrosesan pembelian di atas, Kapsulmu tidak memerlukan identifikasi pengguna untuk fitur lainnya — permintaan konten belajar bersifat anonim dan tidak ditautkan ke identitas Anda karena Kapsulmu tidak memiliki sistem akun.

4. Penyimpanan dan Keamanan Data

  • Data lokal tersimpan di perangkat Anda dan dilindungi oleh sistem keamanan perangkat (enkripsi disk iOS/Android).
  • Karena tidak ada akun atau server yang menyimpan data pribadi Anda, tidak ada risiko kebocoran data dari sisi kami — data sepenuhnya berada dalam kendali Anda di perangkat Anda sendiri.

5. Retensi Data

Data lokal tersimpan di perangkat Anda hingga Anda menghapus aplikasi atau menghapus data aplikasi secara manual melalui pengaturan perangkat. Kami tidak memiliki cara untuk mengakses, mencadangkan, atau memulihkan data ini karena tidak tersimpan di server kami.

6. Hak Pengguna

Karena Kapsulmu tidak menyimpan data pribadi Anda di server, sebagian besar hak privasi (akses, koreksi, penghapusan) dapat Anda lakukan sendiri secara langsung:

  • Menghapus seluruh data aplikasi kapan saja melalui pengaturan penyimpanan perangkat Anda, atau dengan menghapus aplikasi
  • Menarik persetujuan notifikasi kapan saja melalui Pengaturan perangkat

Jika Anda memiliki pertanyaan lain seputar privasi, hubungi kami di: egyadhitama@gmail.com

7. Privasi Anak-Anak

Kapsulmu ditujukan untuk mahasiswa dan profesional farmasi yang berusia 17 tahun ke atas. Kami tidak secara sadar mengumpulkan data pribadi dari anak-anak di bawah usia 13 tahun. Jika Anda mengetahui bahwa seorang anak telah memberikan informasi pribadi kepada kami, hubungi kami segera.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Kami akan memberi tahu Anda tentang perubahan signifikan melalui notifikasi dalam aplikasi atau pembaruan pada halaman ini. Penggunaan berkelanjutan atas aplikasi setelah perubahan dianggap sebagai persetujuan Anda.

9. Hukum yang Berlaku

Kebijakan privasi ini tunduk pada hukum Republik Indonesia, termasuk Undang-Undang Nomor 27 Tahun 2022 tentang Perlindungan Data Pribadi (UU PDP).
